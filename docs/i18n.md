# Idiomas de Safety Desarrollo

La app se puede usar en 9 idiomas: es, ca, en, fr, de, it, pt, pl y ro. El español es la referencia.

## Piezas

- `src/i18n/core.js` contiene `LANGS`, `t(key, vars)`, `getLang()`, `setLang()` y `getIntlLocale()`. No usa React, así que se puede llamar desde `lib/*`.
  - El idioma de la primera carga se busca en este orden: localStorage `safety_dev_locale`, después `portal_locale` del portal y, si no hay ninguno, `es`.
- `src/i18n/I18nProvider.jsx` envuelve la app. En los componentes se usa `const { t, lang, locale } = useI18n()`.
- `src/i18n/LanguageSelect.jsx` es el selector de la cabecera.
- `src/i18n/labels.js` traduce los valores que vienen del backend:
  - `familyName(family)`, `fieldLabel(familyCode, field)` y `caminoLabel(camino)` usan el código y, si no lo encuentran, el texto del backend.
  - `deliverableText(texto)` traduce un entregable solo si coincide con una plantilla estándar.
  - Los mensajes de error se generan en `api/client.js`: `err.message` y `err.fields` llegan ya traducidos.
- `lib/format.js` (`labelOf`, `phaseLabelOf`, `formatDate`, `formatMoney`, `relativeDays`…) ya sigue el idioma activo.
- Diccionarios: `src/i18n/<lang>/<área>.js`, objetos anidados. La clave completa es `<área>.<clave>`, por ejemplo `panel.title`.
  - `catalog.js` recoge las listas fijas del backend (enum, phase, camino, family, field, deliverable, errors).
  - `common.js` recoge textos genéricos (save, cancel…).

## Reglas

- **Variables:** `t('list.count', { count: n, name })`, con `{name}` dentro del texto.
- **Plurales:** claves `x_one` y `x_other`; polaco, rumano y otros añaden `_few` y `_many` según `Intl.PluralRules`. Se llama a `t('x', { count })`.
- **Qué se traduce:** no se traduce lo que escribe la gente (nombres de proyecto, notas, acciones, entregables propios), los nombres de personas o empresas ni los códigos.
- **Test:** `src/i18n/i18n.test.js` falla si a un idioma le falta una clave del español, si tiene claves de más, si altera las `{variables}` o si deja un texto vacío.
